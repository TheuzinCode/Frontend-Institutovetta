# Instituto Vetta — Website Institucional

Website institucional desenvolvido para o Instituto Vetta Profissionalizante, escola de cursos livres com unidades na zona sul de São Paulo. O projeto foi criado com foco em uma experiência moderna, responsiva e intuitiva, apresentando os cursos, as informações da instituição e facilitando o contato com futuros alunos.

## Objetivo

O objetivo é fortalecer a presença digital do Instituto Vetta, oferecendo uma plataforma profissional para divulgação dos cursos e captação de novos estudantes.

## Funcionalidades

- Navegação SPA com React Router
- Catálogo de cursos consumido de API, com paginação e filtros por categoria e modalidade
- Landing pages de captação: uma com CTA direto para o WhatsApp e outra com formulário
- Botão flutuante de WhatsApp com mensagem pré-preenchida
- Página de contato com mapas das duas unidades
- Layout responsivo

## Tecnologias Utilizadas

- React
- HTML5
- CSS3
- JavaScript
